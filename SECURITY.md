# Security Policy

## Supported versions

Only the latest release and the `main` branch receive fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting:

<https://github.com/FFFengMJL/gnome-pinyin-search/security/advisories/new>

Include the GNOME Shell version, session type, a description of the impact, and
reproduction steps if possible. You should receive a response within a few
weeks.

Because this extension runs inside the GNOME Shell process, issues that can
crash the shell or execute unintended code are treated as security issues.
